# Relocating compiler symbols onto the unchanged production binary

The naive `--emit-symbol-map` relink **failed byte identity**. Its functions/imports are ordered differently, so using its symbol names at the same numeric index would be wrong. A normal relink without that option is [fully byte-identical to production](no-map-byte-identity.json). Neither relink replaced the production runtime.

A separate [structural proof](proof.json) establishes a unique complete bijection between all **223 defined functions and eight imports** of the two binaries. Every function's complete instruction text and type is identical after translating only direct-call/function-reference indices. Tables, element references, exports, memory, globals and data are also identical under that mapping. Host imports have the same types and actual JavaScript bindings; all remaining JavaScript glue is byte-identical. No arithmetic, condition, guard, instruction ordering or indirect-call type is normalized away.

The [independent review and binary-to-WAT binding](independent-wat-binding.json) regenerates both representations directly from the binaries and confirms exact WAT hashes. Production SHA is `603679fbc7961ddad95ac8822257074fecde5940bc013246d520ea3b6240c84f`; the symbol build is `e3ea1df9e5f6bf8aa2215bbb7de45096aa31e48ae47427ed1b188f6af56020b1`. The [original compiler symbol map](emu.js.symbols) is transferred **through the proved bijection**, never by equal index. The [link command and immutable object hashes](command.json) preserve its origin.

[Seven deliberate corruptions](negative-proof.json) are rejected: an instruction constant, direct-call target, table element, export name, memory limits, host import binding and JavaScript glue. Their individual failure messages are in `negative-errors/`. The first proof draft also caught an incorrect assumed function count of 224; actual disassembly contains 223 defined functions. No names were accepted before all complete checks passed.

This recovers function-level symbols, not inlining information. For example, production function81 is `arm_step`;228 is `emu_run`;59 is `region_find`. Work inlined into those functions remains fused. Browser module-bytecode collection timed out after sampling; the parent report retains that separate runtime-module identity limitation.

Reproduction uses WABT1.0.39 from the repository's locked dependencies. Read each actual WASM with `readDebugNames:false`, validate it, and write `toText({foldExprs:false,inlineExport:false})` to `.context/jit-attribution/renumber-proof/{production,symbols}.wat`. Then run [prove.py](prove.py) and [negative.py](negative.py) from the repository root. Their working paths deliberately preserve the original isolated experiment; raw WAT and linked binaries remain in `.context`. Compare regenerated WAT hashes with the independent binding report before trusting the result.
