# Unused generated-register transfers: isolated experiment

Production remains on the original compiler and seed. This experiment removes a region's unconditional register spill only if no instruction can write that register. It removes the initial load only if no instruction reads or writes it. Written registers retain their entry loads even when write-only: skipped conditions and early exits must preserve the original value. The original instruction bodies, raw-code checks, memory/alias guards, budgets, input and ABI stay intact.

The [static inventory](inventory.json) finds 1,980 removable spills and 1,580 removable loads across 512 regions. A separately instrumented, exactly equivalent [100M entry census](census.json) weights these at 25.90% of nominal spill operations and 20.56% of nominal loads. These are emitter operations, not measured host instructions or a speed forecast; the host optimizer may already remove some.

The [focused oracle](focused-report.json) passes 2,335 three-engine cases, including 480 zero budgets, 12 actual physical aliases, conditional and write-only destinations, stale instructions, prior work and bounded exits. Architectural state, full 1MiB RAM hash and all memory/generated counters match. Deliberately removing a required load or spill fails the architectural comparison; see the retained negative reports.

The [full proof](proof.json) records fresh 600M replays for both MBX and software phone fixtures. All twelve raw snapshots and all original generated/TLB counters match previously verified same-runtime interpreter/original references, with no normalization. The runtime is production SHA `603679fbc7961ddad95ac8822257074fecde5940bc013246d520ea3b6240c84f`. The candidate seed SHA is `c6b855944ba9b1cd172a01668a994032be32c4a164dd86a5087a20cff0b05b19`, 12,316,393 bytes (24,920 smaller). Admissions are byte-identical. A first attempt failed before guest execution because the isolated runtime lacked its production CommonJS package metadata; the failure is retained separately.

Sources and raw reports are stored here; working binaries and firmware fixtures remain under `.context/jit-register-layout/`. The original generator/compiler and current runtime supply the reproducible base. `omit-unused.fragment.cjs` is appended to an exact copy of `tools/jit/compiler.cjs`; `test.cjs` uses its recorded oracle and candidate/negative paths. The scripts preserve their original repository-relative experiment paths. This candidate is separate from the parked coverage, POP and raw-guard experiments.


The structural check confirms all 512 non-transfer WAT bodies and compiler metadata remain identical, with exactly 1,580 loads and 1,980 spills removed. Quiet alternating 600M measurements are original **24.034760 / 23.800708 seconds**, candidate **23.778380 / 24.077312 seconds**. The forward advantage is 1.067%, but the reverse pair is -1.162%; the combined result is -0.042%, effectively a tie. All 24 full raw checkpoints and original counters pass. These times sum synchronous emulator-run intervals, excluding compile/import/checkpoint hashing; they are not scheduler CPU measurements. **Parked without promotion**: fewer nominal transfers did not produce a repeatable throughput gain. Actual browser stack sampling is the next investigation.
