One isolated Stage V run preserves the complete Stage U stream and then follows the original BSU lock and DMA-pause sequence. The guest acquires the actual modeled decoder resource, separately pauses its outstanding input transfer, disables transport, and reads back the real current/start/count. Its original code saves current physical BYTE address `14ae1568` and **3,750 remaining words**:346 of4,096 words have been copied. Outstanding DMA ownership remains active; no completion or input interrupt is invented.

The run stops before returning the first unsupported BSU state-register read, AMC+410 at original PC `c0277dfc`, LR `c0271af8`, cycle `9874729099`. The stopped instruction has not retired. The diagnostic `value00000000` is the stop argument, **not a supplied register value**. Three earlier control stores have actual mapped original instructions, full CPSR, pre-step/callback/end cycles, successors and returned `emu_run` receipts. Four real control/readback values and the original saved driver fields are independently checked.
